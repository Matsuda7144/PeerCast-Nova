# 内蔵 FLV プレイヤーのセットアップ（Windows x64）

Windows x64 版の Nova で、libmpv を使って FLV チャンネルを内蔵ウィンドウで再生する手順です。

## libmpv を入手する

1. mpv v0.42.0 のリリースページで、**libmpv (Windows)** にある **x86_64 (LGPL)** をダウンロードします。 [リリースページ](https://github.com/mpv-player/mpv/releases/tag/v0.42.0) · [ZIP を直接ダウンロード](https://github.com/mpv-player/mpv/releases/download/v0.42.0/libmpv-v0.42.0-x86_64-w64-mingw32-lgpl.zip)
2. ZIP を展開し、展開したフォルダーをドキュメント内など今後も使う場所に置きます。
3. 展開先に `libmpv-2.dll` があることを確認します。手元に互換性のある `libmpv-2.dll` がある場合は、そのファイルを使えます。

## Nova で設定する

1. Modern の **設定 → 再生** を開きます。
2. **内蔵プレイヤー** を選び、**参照…** で `libmpv-2.dll` を指定します。
3. **保存** を押します。保存した設定は次の再生から使われます。
4. FLV チャンネルを選んで **再生** を押します。映像は **PeerCast Nova - FLV Playback** ウィンドウに表示されます。すでに再生中なら、**停止** してから **再生** を押します。

2026年11月21日に、Windows x64 向けの libmpv v0.42.0（LGPL 版）を指定した Nova の内蔵 FLV 再生で、利用者が映像と音声を確認しました。

## 再生できないとき

- DLL を読み込めない場合は、Windows x64 向けの ZIP を展開したことと、指定したファイルが保存時と同じ場所にあることを確認します。フォルダーを移動した場合は、移動後のパスを指定し直して保存します。
- `--libmpv-library` または `--pcrplayer-executable` を付けて起動した場合は、その指定が優先されます。設定画面で保存した選択を使うには、これらのオプションを付けずに Nova を起動します。
- 外部プレイヤーへ切り替えるには、**設定 → 再生** で **外部プレイヤー** を選んで保存します。
