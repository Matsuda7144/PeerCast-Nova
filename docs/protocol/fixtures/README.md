# Protocol Fixtures

This directory documents both synthetic fixtures and later sanitized captures.

## Synthetic fixtures

Synthetic fixtures are generated by PeerCast Nova and test framing behavior
without claiming interoperability.

## Captured fixtures

Captured fixtures will be added only during controlled interoperability testing.

PCN-0014 records a content-free CHAN structure observation. No exact traffic
bytes or metadata values were retained, so it is not labeled as a captured
binary fixture. The corresponding decoder tests use only Nova-generated
synthetic values arranged in the independently observed shape.

Rules:

- Capture only traffic from systems operated for the test.
- Remove public IP addresses, channel identifiers, and user-generated metadata.
- Record the PeerCastStation version and test topology.
- Preserve exact bytes after sanitization.
- Add the expected parser result and failure mode.
- Do not copy source code from incompatible-licensed implementations.
- No production-user traffic belongs in this repository.
