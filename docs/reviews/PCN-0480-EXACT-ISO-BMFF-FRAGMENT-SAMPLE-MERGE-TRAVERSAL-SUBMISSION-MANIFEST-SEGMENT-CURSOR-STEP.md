# PCN-0480: Exact ISO BMFF Fragment Sample Merge Traversal Submission Manifest Segment Cursor Step

## Scope reviewed

- exact one-segment immutable advancement over the same source projection;
- exact source cursor and segment identity plus terminal rejection;
- no acknowledgement, completion, payload, runtime, dispatch, or physical path.

## Verification

- focused managed tests cover exact advancement, source immutability, missing
  input, and terminal rejection;
- repository routine managed verification remains required for the cumulative
  worktree.

## Result

Accepted as the exact cursor-step boundary defined by ADR-0470.
