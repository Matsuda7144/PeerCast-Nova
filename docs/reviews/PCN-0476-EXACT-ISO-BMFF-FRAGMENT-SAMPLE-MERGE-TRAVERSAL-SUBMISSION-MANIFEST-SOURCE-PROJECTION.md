# PCN-0476: Exact ISO BMFF Fragment Sample Merge Traversal Submission Manifest Source Projection

## Scope reviewed

- exact reference binding from manifest through selection, classification, and
  intent to its original consumer batch;
- missing and foreign-source rejection;
- no payload, authorization, runtime, invocation, dispatch, or physical path.

## Verification

- focused managed tests cover exact binding, missing inputs, and foreign batch
  rejection;
- repository routine managed verification remains required for the cumulative
  worktree.

## Result

Accepted as the exact manifest-source boundary defined by ADR-0466.
