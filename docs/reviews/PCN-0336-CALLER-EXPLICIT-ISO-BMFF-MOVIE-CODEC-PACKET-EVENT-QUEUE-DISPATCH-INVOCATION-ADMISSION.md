# PCN-0336: Caller-Explicit ISO BMFF Movie Codec Packet Event Queue Dispatch Invocation Admission

## Decision

Accept caller-explicit admitted/denied classification for every exact
source-ordered invocation intent, with invocation, sequence, lookup, and opaque
runtime identity revalidation. This is immutable classification metadata, not
an authorization packet; no runtime access, lease, invocation, dispatch,
native operation, rendering, or physical execution occurs.
