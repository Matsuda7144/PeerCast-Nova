# PCN-0473: Caller-Explicit ISO BMFF Fragment Sample Merge Traversal Submission Classification

## Scope reviewed

- exact caller-provided `Include` or `Exclude` facts for every intent;
- source-order identity, exact count, enum, and aggregate-count validation;
- no authorization, selection, payload, runtime, dispatch, or physical path.

## Verification

- focused managed tests cover populated and empty classification plus missing,
  count-mismatched, and undefined dispositions;
- repository routine managed verification remains required for the cumulative
  worktree.

## Result

Accepted as the descriptive classification boundary defined by ADR-0463.
