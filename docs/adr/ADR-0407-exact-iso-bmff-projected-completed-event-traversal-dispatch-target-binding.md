# ADR-0407: Exact ISO BMFF Projected Completed-Event Traversal Dispatch Target Binding

## Status

Accepted as a post-0.0.10e non-physical managed composition-foundation slice.

## Decision

Bind every exact ADR-0405 candidate to the same-media opaque target declared by
ADR-0406. Retain the complete projected source, candidate identity, and target
identity, and reject absent or mismatched media targets.

## Non-goals

Request projection, capability discovery, registry access, delivery,
invocation, native execution, rendering, or physical execution are not
included.
