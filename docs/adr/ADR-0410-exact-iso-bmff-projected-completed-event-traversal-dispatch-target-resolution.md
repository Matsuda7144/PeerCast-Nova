# ADR-0410: Exact ISO BMFF Projected Completed-Event Traversal Dispatch Target Resolution

## Status

Accepted as a post-0.0.10e non-physical managed composition-foundation slice.

## Decision

Resolve every exact ADR-0408 request against the same-target, same-media
ADR-0409 capability and enforce its declared payload limit. Retain the complete
projected source, exact request identity, and exact capability identity.

## Non-goals

Runtime target registry access, instance resolution, request submission,
delivery, invocation, native execution, rendering, or physical execution are
not included.
