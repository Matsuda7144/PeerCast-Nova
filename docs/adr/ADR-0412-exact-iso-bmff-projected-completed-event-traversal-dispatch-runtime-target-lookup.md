# ADR-0412: Exact ISO BMFF Projected Completed-Event Traversal Dispatch Runtime-Target Lookup

## Status

Accepted as a post-0.0.10e non-physical managed composition-foundation slice.

## Decision

Match every exact ADR-0410 resolution to the same-target and same-media opaque
ADR-0411 registration. Retain the complete projected source, registration
identity, opaque runtime-instance ID, and positive generation.

## Non-goals

Runtime object resolution, instance access, target calls, request submission,
delivery, invocation, native execution, rendering, or physical execution are
not included.
