# 0.0.10d Controlled Decoded-Audio Slice Probe

## Purpose

Determine whether the chronological first 80 ms of the retained fixture's
actual decoded AAC audio is recognizable when sent once through the production
Windows audio buffer path already proven by the known-tone probe.

This is a separately approved physical diagnostic. Do not execute it from the
implementation PR.

## Fixed inputs

- Runtime build: `btbn.ffmpeg.20260721.win64.lgpl-shared`
- Fixture: `pcn-0.0.10b-controlled-h264-aac-flv-v1`
- Fixture bytes: `66,939`
- Fixture SHA-256:
  `32872B300286525F4EF97FEE3533E25419AC8E48BFD4BC2C4FD9545F071B1E15`

Keep the runtime, fixture, record, and decoded payload outside the repository.

## Command

From a clean approved `main` on Windows:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\Run-ControlledWindowsDecodedAudioSliceProbe.ps1 `
  -ExpectedCommit <APPROVED_MAIN_SHA> `
  -RuntimeDirectory 'C:\path\to\approved-ffmpeg-bin' `
  -FixturePath 'C:\path\to\retained-controlled.flv' `
  -RecordPath 'C:\path\outside-repository\unused-decoded-slice-record.txt'
```

Keep the defaults:

- `MaximumDecodeOperations=128`
- `FixturePacketBytes=65536`
- `ObservationHoldMilliseconds=1000`

The helper verifies exact clean main, `HEAD`/`origin/main`, five load-role DLL
sizes and hashes, fixture size/digest, and a new external record path. It
restores and Release-builds the runner, executes the command once, and
atomically promotes a complete canonical record.

## Required result

Acceptance requires exactly four decoded audio frames consumed, three complete
frames copied, 768 sample frames copied from the fourth, 3,840 total sample
frames, 30,720 bytes, one native write/acknowledgement, one Start
acknowledgement, zero retained WouldBlock, zero video Present, stopped runner,
disposed lifecycle, and preserved borrowed owners.

Only after deterministic acceptance answer:

```text
Decoded fixture audio recognizable: Yes
```

if the short fixture sound is clearly recognizable, or:

```text
Decoded fixture audio recognizable: No
```

for noise, click, silence, or uncertainty. The mere presence of sound is not
enough for `Yes`.

## Stop conditions

Every integrity, decode, format, sequence, generation, arithmetic, write,
Start, evidence, or cleanup mismatch is terminal. Do not retry, write twice,
select another slice, repeat or amplify samples, mutate the fixture/runtime,
run another probe, or start paired verification.
