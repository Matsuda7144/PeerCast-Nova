# 0.0.10d Controlled Windows Known-Pattern Probe

## Purpose

Distinguish decoded／converted black pixels from a Windows output／presentation defect after deterministic physical video evidence was accepted but the operator observed only a black window.

This probe uses no FFmpeg runtime and no media fixture. It generates one known non-black BGRA frame and sends it through the same controlled Windows activation, binding, stream, production buffer, D3D11 upload, Present, window, dispatcher, and cleanup boundaries.

## Fixed pattern

- Identity: `Bgra32QuadrantsV1`
- Dimensions: 320×240
- Stride: 1,280 bytes
- Payload: 307,200 bytes
- Pixels: 76,800 opaque non-black pixels
- Layout: red upper-left, green upper-right, blue lower-left, white lower-right

No generated pixel payload is written to the repository or canonical record.

## Preconditions

1. Use Windows 11 with a visible interactive desktop.
2. Check out `main` at the explicitly approved commit.
3. Keep the Git working tree clean.
4. Choose a new repository-external record path.
5. Do not start audio or paired verification.

## Command

From the PeerCast Nova repository root:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Run-ControlledWindowsKnownPatternProbe.ps1 `
  -ExpectedCommit <APPROVED_MAIN_SHA> `
  -RecordPath 'C:\path\outside-repository\pcn-0.0.10d-known-pattern-record.txt'
```

The helper restores and builds the dedicated Release runner, executes exactly one known-pattern probe, holds the presented frame for three seconds, retains one canonical UTF-8 record outside the repository, validates its fixed fields, and confirms that Git remains clean.

The hold may be explicitly overridden with `-ObservationHoldMilliseconds` within 0 through 30,000 milliseconds. No additional output call occurs during the hold.

## Operator observation

During the hold, inspect the controlled output window. After it closes, report exactly one observation:

```text

```

or

```text

```

`Yes` requires recognizable red, green, blue, and white quadrants. A black window alone is `No`.
